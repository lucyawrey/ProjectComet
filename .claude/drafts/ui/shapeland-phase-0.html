Look

Carrying it over to UI Toolkit

Plain: dark see-through panels, one blue accent, Atkinson Hyperlegible (designed for legibility; free licence). Cheapest to build and the easiest to read over any background.

Toy box: white panels with thick ink outlines and a thicker bottom edge for a pressable, chunky feel, done with per-side border widths. Fredoka (free licence). Matches the shapes; the most work to keep consistent.

Translucent: light, see-through panels with white text and a text shadow, Lexend (free licence). UI Toolkit can't blur what's behind a panel, so this is plain transparency; it reads worst over bright sky.

  • Everything in the screens uses only what USS supports: flexbox with margins (USS has no gap), borders per side, rounded corners, transparency, text shadow, translate and rotate, and fades through transitions. No drop shadows, gradients, blur or grid.
  • Laid out at a 960 × 600 reference resolution; in Unity the panel scales with the screen, and a UI scale setting can multiply it later.
  • Shape icons and the bubble tail (a rotated square) port as they are; the preview is a render texture of the real shape mesh, not a drawing.
  • Name labels and bubbles are world-space panels that follow each shape and keep a fixed size on screen.
