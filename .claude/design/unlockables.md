# Unlockables

**Layer: mixed.** Base (Comet): unlockables as learned flags; "soul" names as theming over ordinary values. Game (Project Anima): attunements, Anima Capacity, quest-granted Runes.

Agent notes on unlockables: progression not tied to items, companions, or class and craft levels.

## Decided

- **Unlockables are learned flags** (see `items.md`).
- **Found collectables are learned flags too,** one per placed collectable, grouped into collections that count them (`world.md`).
- **"Soul" is theming:** Soul XP and Anima are player-facing names for ordinary character data.
- **Anima Capacity is a number on the character.** It's raised by:
  - spending Soul XP,
  - quest rewards,
  - rare items, each usable once per character.
- **Flight Attunements are per region.** Flying needs both a flying mount and the region's attunement (see `companions.md`).
- **Teleportation Attunements are per destination.**
- **Attunements are earned through exploration and quests.**
- **Teleporting to an attuned destination costs Anima.**
- **Many game mechanics come as Runes given by quests** (see `skills.md`), such as the XP-to-Soul World Rune (`classes.md`).
- **Magical appearance changes and ancestry changes** are unlocked by quests (`proposal.md`, character creation).
