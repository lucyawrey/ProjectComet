## Working on the docs

The docs are an Obsidian vault: open the repo root with "Open folder as vault".

The vault's shared config and community plugins are committed, so they're ready after cloning (enable community plugins if Obsidian asks):

- **Unhide for Obsidian**: shows dot-folders, including `.claude/` (agent notes). `.git` stays hidden.
- **Git**: commit and pull from inside Obsidian.

Per-user state (open tabs, graph settings, Git plugin settings) is git-ignored.
