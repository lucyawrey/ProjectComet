# Class: Class Name

**Tier**: How far into the game is this class?
**Unlock**: How is the class unlocked (usually promotes from a lower tier class)
**Roles**: One or more roles: Support, Damage, Tank
**Weapons**: One or more weapon types the class uses
**Class Appeal**: One line about the main draw to playing this class.
**Aesthetic**: The visual language of the class.
**Central Mechanic**: The mechanic the class revolves around that makes understanding its skills and traits easier.
**Class Resource**: A class's other resources that are not HP, MP, or SP.
