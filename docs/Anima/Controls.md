# Controls

Default gamepad scheme. Players can rebind everything. Draft: details to come.

Face buttons are named by position (South, East, West, North) so the layout holds across controllers.

## Base layer

| Input | Action |
| --- | --- |
| L1 | Modifier (hold) |
| L2 | Lock on (hold). While held, switch targets with either stick or the d-pad |
| R1 | Primary |
| R2 | Secondary |
| Left stick click | Sprint |
| Right stick click | Crouch |
| South | Jump / interact / confirm |
| East | Mobility dash / cancel |
| West | Technique 1 |
| North | Technique 2 |
| D-pad | Extra skills |
| Start | Menu |
| Select | Map |

## Modifier layer (hold L1)

| Input | Action |
| --- | --- |
| R1 | Special |
| R2 | Defensive |
| West | Technique 3 |
| North | Technique 4 |

## Open questions

- Consumables and healing: do they live in the d-pad extra skills, or get their own quick-use slot?
- Camera reset (tap L2 with no target?).
- Unassigned modifier combos: South, East, stick clicks, d-pad (a second skill page?), Start and Select.
- Menu navigation: tab switching, details, what the stick clicks do.
- Ping, emote, photo mode, chat.
- Jump versus interact priority when both are possible on South.
- Defense is Modifier + R2, which takes two fingers; check it against reaction-critical blocking.
- Hold versus toggle options (lock on, sprint, crouch, modifier) and other accessibility settings.
- Stick sensitivity and invert options.
- Separate keyboard and mouse defaults, and Steam Deck back buttons.
- Tap versus hold on one button as separate actions.
